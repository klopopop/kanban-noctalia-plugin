# Changelog

## 0.2.0 — 2026-11-13

- Несколько досок: папка `boards_dir` (по умолчанию `~/Documents/obsidian/kanban-boards`), вкладки рукописным шрифтом, новая доска, переименование (= файла), удаление в корзину системы.
- Фоновая служба: IPC `add` (быстрое добавление, Win+Alt+K через `extras/hyprland/kanban-clip.sh`) и `check`; напоминания о сроках раз в день на карточку.
- Значок на панели Noctalia: карточки «в работе», красный при просрочке.
- Виджет рабочего стола: карточки «в работе» мини-листками.
- Лаунчер `/kb`: добавить карточку в любую колонку, поиск по карточкам.
- Сроки `@{ГГГГ-ММ-ДД}`: подпись на листке, красный скотч у просроченных, кнопки в правке.
- Метки `#тег`: подпись на листке, фильтр над колонками.
- Цвет листка вручную; архив (`***` / `## Archive`) вместо удаления у «готово».
- Общие модули `store.luau` (состояние, текущая доска) и `board.luau` (формат).
